# KING-Laptop-Store-Website-System
A System Analysis and Design project focused on designing a laptop retail website integrated with ERP ERZAP to streamline online sales, inventory management, and stock synchronization.

# Project Scope
- Requirements Analysis
- Business Process Modeling
- Use Case Diagram & Description
- Entity Relationship Diagram (ERD)
- AI-Based Stock Transfer Recommendation (Proposed Feature)

# Tools
Draw.io | ERD | System Modeling
